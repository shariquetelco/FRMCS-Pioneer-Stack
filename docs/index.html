Episodes

Episode 01 · RailGuard-PKI

PKI identity and authorization platform implementing ETSI TS 102941 AT issuance with ECDSA-P256.

GitHub Repository

Episode 02 · RailThreat

RF threat detection engine using an 11-feature PLS+RAN classifier detecting jamming, spoofing and replay attacks.

GitHub Repository

Episode 03 · FRMCS-RAIL-IQ

Corridor-level orchestration engine propagating threat risk across a Munich-Augsburg tower chain.

GitHub Repository

Episode 04 · RailWave

Real SDR FRMCS testbed validating RF threats and digital twin models using NVIDIA Sionna.

Episode 05 · RailShield

Kernel level anomaly detection using eBPF and XDP integrated with RF threat indicators.

Episode 06 · Rail-QSecure

Post-quantum cryptography replacing ECDSA with ML-KEM and ML-DSA for FRMCS identity protection.

Episode 07 · RailOrbit

Satellite fallback platform enabling NTN failover during terrestrial corridor failure.
