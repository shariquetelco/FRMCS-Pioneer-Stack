The Stack

7 Episodes · End-to-End Coverage

Episode 01 · Identity Layer
RailGuard-PKI
PKI-based device identity and authorization engine for FRMCS. Implements ETSI TS 102941 AT issuance using ECDSA-P256. NOC dashboard + Rail-AA terminal with BroadcastChannel sync.
ECDSA-P256 ETSI TS 102941 ECIES HKDF-SHA256 Flask
✅ Complete → GitHub
Episode 02 · Detection Layer
RailThreat-FRMCS-LAB
RF and RAN threat detection engine. 11-feature PLS+RAN fusion classifier detects jamming, spoofing, replay attacks with confidence scoring. Prometheus + Grafana observability.
FastAPI scikit-learn 11-feature PLS+RAN Prometheus Grafana
🔄 Building → GitHub
Episode 03 · Orchestration Layer
FRMCS-RAIL-IQ
Corridor-level risk orchestration. Adjacency-weighted threat propagation across 10 Munich–Augsburg towers. Deterministic response: PKI pause, handover prep, NTN standby.
FastAPI Risk Engine React Leaflet Claude Haiku
🔄 Building → GitHub
Episode 04 · RF Layer
RailWave
Real SDR FRMCS testbed. USRP X310 as gNB, B210 as UE, HackRF for interference injection. Validates NVIDIA Sionna digital twin against measured RF metrics.
OAI Open5GS GNU Radio NVIDIA Sionna USRP X310
📋 Planned
Episode 05 · Kernel Defense
RailShield
Kernel-level packet anomaly detection. Combines eBPF/XDP with RF KPIs from Episode 2. Correlates network-layer anomalies with radio threat classifications in real time.
eBPF XDP libbpf bcc Prometheus
📋 Planned
Episode 06 · Crypto Evolution
Rail-QSecure
Post-quantum cryptography for FRMCS identity. Replaces ECDSA-P256 with ML-KEM and ML-DSA. Evaluates rekeying performance under degraded RF from Episode 4.
ML-KEM (Kyber) ML-DSA (Dilithium) liboqs NIST PQC
📋 Planned
Episode 07 · Satellite Fallback
RailOrbit
Terrestrial to satellite failover triggered by Episode 3. GEO/LEO simulation with delay injection. Validates FRMCS service continuity under total terrestrial corridor failure.
OAI NTN n254 S-band GEO/LEO sim Open5GS
