PKI-based device identity and authorization engine for FRMCS. Implements ETSI TS 102941 Authorization Ticket issuance using ECDSA-P256. Includes NOC dashboard and Rail-AA terminal.

Corridor-level risk orchestration engine. Models adjacency threat propagation across 10 Munich–Augsburg towers. Fires deterministic response actions: PKI pause, handover, NTN standby.

RailWave
Real SDR FRMCS testbed validating NVIDIA Sionna digital twin against measured RF metrics. USRP X310 as gNB, B210 as UE, HackRF for interference injection.

RailShield

RESEARCH CONTEXT

This stack targets IEEE VTC 2026. It demonstrates the first open, end-to-end FRMCS security architecture covering RF detection, corridor orchestration, PKI identity management, kernel defense, post-quantum cryptography, and satellite failover in a single connected system.
